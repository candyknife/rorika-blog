深度学习服务器环境配置指南 2：训练环境

January 7, 2023

一、Miniconda 安装#

  1. 下载安装包 Miniconda

  2. 验证哈希值

    sha256sum filename

  3. 安装

    bash Miniconda3-latest-Linux-x86_64.sh

  4. 重启终端并测试

    conda list

  5. 更新

    conda update conda

二、项目环境配置#

根据需要为项目创建对应环境。

conda create -n project_name

激活项目环境。

conda activate project_name

三、Pytorch 安装#

查看当前 Nvidia 驱动版本。

nvidia-smi

查找对应的 cuda 版本：CUDA documentation。 根据 cuda 版本执行对应的安装指令：PyTorch。

conda install pytorch torchvision torchaudio pytorch-cuda=11.7 -c pytorch -c nvidia

四、Jupyter Notebook 安装#

安装：

conda install notebook

生成配置文件并修改：

jupyter notebook --generate-config
vi ~/.jupyter/jupyter_notebook_config.py

单独打开一个终端窗口用以生成密钥：

python

from notebook.auth import passwd
passwd()

Enter password:
Verify password:
'argon2:$argon2id$...'

在 Jupyter Notebook 的配置文件中改动以下内容：

c.NotebookApp.allow_remote_access = True
c.NotebookApp.open_browser = False
c.NotebookApp.notebook_dir = './jupyter'
c.NotebookApp.password = u'argon2:$argon2id$...'
c.NotebookApp.password_required = True
c.NotebookApp.ip = '*'
c.NotebookApp.port = 7777
